# Queries

Write one SPARQL file per competency question, named `cq01.rq`, `cq02.rq` and so on. Start each file with a comment that repeats the question.

Run them against `ontology/wine.ttl` together with `examples/*.ttl`. For questions marked "needs reasoning", run them after the reasoner, or against the inferred graph exported from Protégé, and note any difference in the results.
